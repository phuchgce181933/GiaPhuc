# PHASE 30 — model runtime stack.
#
# INSTALLED SEPARATELY, AND ONLY ON A MACHINE THAT WILL RUN INFERENCE.
#
#     pip install -r requirements-model.txt
#
# The default test suite does NOT need any of this. `app/runtime.py`
# imports airllm, torch, and transformers inside functions, so
# `pytest` passes on a host that has never installed them (brief 45).
#
# WHY AIRLLM IS NOT PINNED TO AN EXACT VERSION
# --------------------------------------------
# AirLLM is pre-1.0-track and its dependencies (transformers in
# particular) move quickly; an exact pin here would produce
# dependency conflicts on hosts that already have a working torch.
# The compatible-release range below is the widest that is known to
# work with the adapter in app/runtime.py. Before deploying, read the
# version actually installed and record it in
# docs/PHASE_30_AIRLLM_LOCAL_PROVIDER.md (brief 48), because
# "AirLLM supports this model" is not the same claim as "this model
# was smoke-tested here" (brief 42).
#
# TORCH AND CUDA
# --------------
# torch is deliberately NOT pinned to a version. The correct wheel is
# chosen by the CUDA version of the host, and pinning it here would
# override that choice. Install torch first, following
# https://pytorch.org for the host's CUDA version, then install the
# rest of this file.

airllm>=4.0.0
transformers>=4.40
