# ISOLATION (brief 39)
# --------------------
# These packages are used by the Python service ONLY. None of them
# appears in backend/package.json, and the Node test suite does not
# import, require, or check for any of them. `npm test` passes on a
# machine that has never run `pip install` (brief 45).
#
# The heavy model stack (torch / transformers / airllm) is pinned in
# requirements-model.txt rather than here. Reason: installing torch is
# a multi-gigabyte operation that depends on the CUDA version of the
# host, and pinning a wheel index here would make a plain
# `pip install -r requirements.txt` on a CPU-only laptop either pull
# the wrong build or fail. The service code imports none of them
# eagerly, so the default test suite runs without them.
